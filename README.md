# Cryptography-Algorithm-Visualizers
An interactive educational platform to visually guide you on how popular cryptography algorithms actually work to strengthen understanding and provide education on the algorithms that make encryption and security possible.

# Features
Interactive algorithm visualizations
Educational explanations of each algorithm
Simple and responsive web interface
Pure HTML, CSS, and JavaScript
Runs entirely in the browser

# Included Algorithms
Asymmetric Cryptography:
RSA
Elliptic Curve Cryptography (ECC)
Diffie-Hellman Key Exchange

Symmetric Cryptography:
AES
DES
ChaCha20

Hash Functions:
SHA-256
MD5
BLAKE3

Purpose

This project is intended as an educational resource to help students and anyone interested in cybersecurity and cryptography better understand the fundamental principles behind widely used encryption, key exchange, and hashing algorithms through interactive visualizations.
