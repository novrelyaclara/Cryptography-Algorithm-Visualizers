STEP 1: Secret Key & Key Expansion

Enter a 16-character (128-bit) secret key to generate the round keys needed for substitution and mixing layers.

Why do we need Key Expansion & Round Keys?

Symmetric Cipher: AES uses the same secret key for both encryption and decryption.
Key Expansion: AES-128 expands a single 16-byte key into 11 distinct 16-byte round keys using Rijndael's key schedule.
Each transformation round combines the state matrix with its corresponding round key using bitwise XOR (`AddRoundKey`).

STEP 2: Plaintext Input & 4x4 State Matrix

Input a 16-byte plaintext string to map into the initial 4x4 column-major State Matrix.

How does the 4x4 State Matrix work?

AES processes data in 128-bit blocks represented as a 4×4 byte matrix.
Bytes are populated in column-major order: byte 0 is top-left, byte 1 is row 1 column 0, and byte 4 starts the second column.
