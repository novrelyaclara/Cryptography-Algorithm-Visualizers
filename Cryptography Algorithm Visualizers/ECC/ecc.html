STEP 1

STEP 1: Choose Curve Parameters (a, b, p) & Generator Point G

Define the curve y² ≡ x³ + ax + b (mod p). Select a prime field p and valid coefficients where 4a³ + 27b² ≢ 0 (mod p).

Why do we need Prime Field p & Generator Point G?

Prime Modulus (p): Restricts all operations to a finite grid of points (finite field 𝔽ₚ).
Generator Point (G = [Gx, Gy]): A starting point on the curve used to compute public keys through repeated point addition.
Discriminant Condition: 4a³ + 27b² mod p ≠ 0 ensures the curve has no sharp cusps or self-intersections.

How do I pick a Generator Point G easily?

A Generator Point G = (Gx, Gy) must be a coordinate that lies directly on your chosen curve.

1. The Check Equation: A point is valid if (Gy²) mod p equals (Gx³ + a × Gx + b) mod p.
2. Simple Rule of Thumb: Pick a small number for Gx (like 0, 1, or 2), calculate rhs = (Gx³ + a × Gx + b) mod p, and find a whole integer Gy where Gy² mod p = rhs.

Examples:

  • Small Toy Curve: p = 257, a = 2, b = 3 → Gx = 3, Gy = 6
  • Classic Curve: p = 257, a = 1, b = 1 → Gx = 0, Gy = 1

STEP 2

STEP 2: Select Private Key (d) & Derive Public Key Point Q

Pick a private scalar integer d. The public key Q is calculated as Q = d × G using scalar multiplication.

How is Public Key Point Q calculated?

Q is computed by adding base point G to itself d times: Q = G + G + ... + G (d times).
While computing Q from d and G is fast (using double-and-add), finding d from Q and G is extremely hard (the Elliptic Curve Discrete Logarithm Problem).
