STEP 1: Choose Primes (p & q)

Select distinct prime numbers. Pick larger primes (e.g., p=17, q=19 so n=323 > 255) to encrypt full ASCII text sentences!

Why do we need Modulus n & Totient φ(n)?

Modulus (n = p × q): Forms part of both public and private keys. It defines the maximum size of a single message number.
Euler's Totient φ(n) = (p - 1)(q - 1): Counts how many numbers below n share no common factors with n.
This secret value is required to calculate the private key d in Step 2.

STEP 2

STEP 2: Select Public Exponent (e) & Derive Private Key (d)

Must be coprime with φ(n) and 1 < e < φ(n).

How is private exponent d calculated?

d is the modular multiplicative inverse of e modulo φ(n). It satisfies the equation: (d × e) mod φ(n) = 1.
We compute this using the Extended Euclidean Algorithm.
