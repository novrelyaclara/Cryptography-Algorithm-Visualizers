STEP 1: Secret Key & Nonce Setup

Enter a 32-character (256-bit) secret key and a 12-character (96-bit) nonce to initialize the ChaCha20 cipher state.

Why do we need a Secret Key & Nonce?

Symmetric Stream Cipher: ChaCha20 generates a pseudorandom stream of bytes from a key and nonce.
256-Bit Key & 96-Bit Nonce: The key protects secrecy, while the unique nonce ensures that encrypting the same message twice produces different ciphertexts.
State Assembly: Combined with four 32-bit constants and a block counter, these parameters fill a 16-word (64-byte) matrix.

STEP 2: Nonce Input & 4x4 State Matrix

Input a 12-byte nonce string to complete mapping the 4x4 (16-word) ChaCha20 State Matrix.

How does the 4x4 ChaCha20 State Matrix work?

ChaCha20 operates on sixteen 32-bit words laid out in a 4×4 matrix:
Words 0–3: Fixed Constants ("expand 32-byte k") | Words 4–11: 256-bit Secret Key
Word 12: Block Counter | Words 13–15: 96-bit Nonce (Number Used Once).
